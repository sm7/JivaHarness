JivaHarness — Runtime Data Flow

Paper-faithful separation of capability, authorization, action, evaluation, identity, and feedback

Synchronous action path

  • 1. Principal request enters with delegated authority.
  • 2. Scope resolver binds it to Agent DID and Citta genesis.
  • 3. Dharma authorizes before execution.
  • 4–5. Saṅkalpa proposes; gateway enforces; Prakṛti executes.

Evidence path

  • 6. Runtime outcome returns to intrinsic evaluation.
  • 7. Reward and complete (s,g,c,a,r,z) experience append to Citta.
  • Denied requests create decision evidence but no action claim.
  • Merkle identity binds conduct to the same deployed Jīva.

Feedback path

  • Karma aggregates identity-bound history and outcomes.
  • Karmādhyakṣa audits and attributes harm.
  • Policy and learning feedback affect later transitions.
  • Ātman remains capability without identity or runtime governance.
